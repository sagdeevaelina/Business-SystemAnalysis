# Таблица потоков данных

| № | ID потока | Название потока данных | Назначение (цель) потока данных | Направление потока данных |
|:--|:----------|:-----------------------|:--------------------------------|:--------------------------|
| 1.0 | DF-1 | Заказ от магазина / предприятия питания | Получение информации о заказе (состав, место комплектации, место доставки, желаемые сроки) для ввода в систему оператором | В систему |

| 5.0 | DF-5 | Информация о доставке в бухгалтерию | Передача факта выполненной доставки (какой курьер, когда, какой заказ) для расчёта оплаты курьера | Из системы (внешняя ИТ-система бухгалтерии) |
| 6.0 | DF-6 | Начисленная оплата курьеру | Получение из бухгалтерской системы суммы оплаты за доставку для отображения в личном кабинете курьера | В систему (из внешней ИТ-системы бухгалтерии) |
