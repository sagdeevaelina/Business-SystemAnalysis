## Поток №1 (DF-01). Заказ от магазина / предприятия питания

**Назначение:** получение информации о заказе (состав, место комплектации, место доставки, сроки) для ввода в систему оператором  
**Направление:** В систему  
**Мастер-система:** ERP магазина

### Блоки и вложенность

| Блок | Вложенность | Обязательность |
|------|-------------|----------------|
| Заказ | корневой | Обязательный |
| └ Покупатель | внутри Заказа | Обязательный |
| └ Пункт комплектации | внутри Заказа | Обязательный |
| └ Пункт доставки | внутри Заказа | Обязательный |
| └ Товарная позиция | внутри Заказа (повторяется) | Обязательный (1..n) |

### Атрибуты

| Атрибут | Тип данных | Длина | Обязательность | Ограничения / условия |
|---------|------------|-------|----------------|----------------------|
| Заказ.Номер заказа | Строка | 20 | Да | Уникальный в системе |
| Заказ.Дата и время создания | DateTime | - | Да | Формат ГГГГ-ММ-ДД ЧЧ:ММ:СС |
| Заказ.Желаемая дата доставки | Date | - | Да | Не ранее текущей даты |
| Заказ.Крайний срок доставки | DateTime | - | Нет | Должен быть >= желаемой даты |
| Заказ.Статус | Строка | 20 | Да | Фиксированный список: «Новый», «В обработке» |
| Заказ.Сумма к оплате поставщику | Decimal (10,2) | - | Да | >= 0 |
| Покупатель.ФИО | Строка | 100 | Да | Не пусто |
| Покупатель.Телефон | Строка | 20 | Да | +7ХXXXXXXXXX |
| Покупатель.Email | Строка | 100 | Нет | Формат email |
| Пункт комплектации.Адрес | Строка | 200 | Да | Не пусто |
| Пункт комплектации.Название магазина | Строка | 100 | Да | Идентификатор поставщика |
| Пункт доставки.Адрес | Строка | 200 | Да | Не пусто |
| Пункт доставки.Квартира | Строка | 10 | Нет | - |
| Пункт доставки.Домофон | Строка | 20 | Нет | - |
| Товарная позиция.Артикул | Строка | 30 | Да | Не пусто |
| Товарная позиция.Наименование | Строка | 150 | Да | Не пусто |
| Товарная позиция.Количество | Целое | - | Да | > 0 |
| Товарная позиция.Цена за единицу | Decimal (10,2) | - | Да | >= 0 |

## Поток №6 (DF-06). Начисленная оплата курьеру

**Назначение:** получение суммы оплаты за доставку для отображения в личном кабинете курьера  
**Направление:** В систему  
**Мастер-система:** Бухгалтерская ИТ-система

### Блоки и вложенность

| Блок | Вложенность | Обязательность |
|------|-------------|----------------|
| Оплата курьеру | корневой | Обязательный |

### Атрибуты

| Атрибут | Тип данных | Длина | Обязательность | Ограничения / условия |
|---------|------------|-------|----------------|----------------------|
| ID курьера | Целое | - | Да | Существующий в системе |
| Номер заказа | Строка | 20 | Да | Из системы доставки |
| Период расчёта (месяц, год) | Строка | 7 | Да | Формат ГГГГ-ММ |
| Сумма начислено | Decimal (10,2) | - | Да | >= 0 |
| Сумма удержано (налоги и пр.) | Decimal (10,2) | - | Нет | 0 по умолчанию |
| Сумма к выплате | Decimal (10,2) | - | Да | = Начислено − Удержано |
| Дата расчёта | Date | - | Да | Не позже текущей |
| Статус выплаты | Строка | 20 | Да | «Рассчитано», «Выплачено» |
