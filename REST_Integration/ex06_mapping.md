   b. QUERY параметр в url -> Api Backend

   ### Элементы запроса (параметр в URL)

| Идентификатор элемента | Название по бизнесу | Тип элемента | Размерность | Обязательность | Соответствие элементу системы-отправителя | Комментарии |
|------------------------|---------------------|--------------|-------------|----------------|-------------------------------------------|-------------|

 ### Характеристики поля системы отправителя
 | Сущность/класс (идентификатор и название по бизнесу) | Вложенный блок / множественность | Элемент / поле | Тип данных | Размерность | Обязательность | Условия, ограничения | Ссылка на справочник | Соответствие полю тела ответа |

### Маппинг 
Прямой, поле отправителя и получателя соответствуют друг другу полностью


2. Проверка уникальности номепра телефона (ответ) 
 а. API Backend Entity -> API Backend DTO -> JSON responce
  b. JSON responce -> UI

### Характеристики поля системы отправителя (API Backend)
 | Сущность/класс (идентификатор и название по бизнесу) | Вложенный блок / множественность | Элемент / поле | Тип данных | Размерность | Обязательность | Условия, ограничения | Ссылка на справочник | Соответствие полю тела ответа | Тип преобразования |
|------------------------------------------------------|--------------------------------|----------------|-------------|-------------|----------------|----------------------|---------------------|--------------------|------------------|
| коллекция объектов Client | - | - | array[Client] | - | - | - | Clients | boolean "isRegistered" | если коллекция пуста то "true", если нет, то false | 
| - | - | - | - | - | - | - | - | string "message" | если коллекция непуста заполняется значением  "Этот номер телефона уже зарегистрирован" |

### Элементы ответа (200 OK) JSON

| Идентификатор элемента | Название по бизнесу | Тип элемента | Размерность | Обязательность | Соответствие элементу системы-получателя | Комментарии |
|------------------------|---------------------|--------------|-------------|----------------|------------------------------------------|-------------|
| isRegistered | Признак регистрации | boolean | - | Да | Определяет дальнейшее действие менеджера | true — номер занят, false — свободен |
| message | Текст сообщения | string | 255 | Да | Сообщение для отображения менеджеру | Пример: "Номер телефона свободен" |
