 а. API Backend Entity -> API Backend DTO -> JSON responce

### Характеристики поля системы отправителя (API Backend)
 | Сущность/класс (идентификатор и название по бизнесу) |  Элемент / поле | Тип данных | Размерность | Обязательность | Условия, ограничения | Ссылка на справочник | Соответствие полю тела ответа | Тип преобразования |
|------------------------------------------------------|----------------|-------------|-------------|----------------|----------------------|---------------------|--------------------|------------------|
| коллекция объектов Client |  - | array[Client] | - | - | - | Clients | boolean "isRegistered" | если Clients.Count!=0 то "true", если нет, то false | 
| - | - | - | - | - | - | - | - | string "message" | если Clients.Count!=0  заполняется значением "Этот номер телефона уже зарегистрирован" |

### Элементы ответа (200 OK) JSON

| Идентификатор элемента | Название по бизнесу | Тип элемента | Размерность | Обязательность | Соответствие элементу системы-получателя | Комментарии |
|------------------------|---------------------|--------------|-------------|----------------|------------------------------------------|-------------|
| isRegistered | Признак регистрации | boolean | - | Да | Определяет дальнейшее действие менеджера | true — номер занят, false — свободен |
| message | Текст сообщения | string | 255 | Да | Сообщение для отображения менеджеру | Пример: "Номер телефона свободен" |


### Характеристики поля системы получателя
 | Сущность/класс (идентификатор и название по бизнесу) | Элемент / поле | Тип данных | Размерность | Обязательность | Условия, ограничения | Ссылка на справочник | Соответствие элементу ответа
|------------------------------------------------------|----------------|-------------|-------------|----------------|----------------------|---------------------|
| Client.phone | phone | string | 11 | да | только цифры, код страны и региона (4 знака) и остальной номер, пустое не принимается | - |
