# Exercise 03 — Интеграция справочников

## Справочники, используемые в UC04 «Зарегистрировать клиента (менеджер)»

| № | Справочник | Описание | Интеграция требуется? |
|---|------------|----------|----------------------|
| 1 | **Clients** | Таблица зарегистрированных клиентов | Нет |
| 2 | **EmployeeRoles** | Роли сотрудников (менеджер, мастер, администратор) | Нет |
| 3 | **LinkChannelTypes** | Типы каналов связи (SMS, Telegram, WhatsApp, VK, Email) | **Да** |

## Обоснование необходимости интеграции для LinkChannelTypes

Справочник LinkChannelTypes используется на клиентском интерфейсе (UI) при формировании выпадающего списка для выбора предпочтительного канала связи. UI является отдельным сервисом в архитектуре системы, поэтому требуется интеграция для передачи актуальных данных справочника от сервера к клиенту.

## Решение по интеграции справочника LinkChannelTypes

| Справочник | Вариант интеграции | Обоснование |
|------------|-------------------|-------------|
| **LinkChannelTypes** | Полная передача справочника (Full transfer) | Записей в справочнике немного (5-10 записей), изменения происходят крайне редко (добавление нового канала связи, переименование, отключение). За время выполнения UC04 справочник гарантированно не изменится. Предзагрузка полного списка упрощает реализацию и не создаёт значительной нагрузки на систему. |

## Метод интеграции

| Справочник | Метод интеграции |
|------------|------------------|
| **LinkChannelTypes** | REST API: `GET /api/reference/channel-types` |
