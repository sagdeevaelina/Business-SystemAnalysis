## Требования к обработке недоступности внешней системы

### Интеграция №1 — Справочник каналов связи

| Ситуация | Действие | Поведение системы |
|----------|----------|-------------------|
| Сервис недоступен при загрузке страницы регистрации | 3 попытки с интервалом 1 секунда | Отобразить ошибку: "Справочник каналов связи недоступен, повторите попытку позже" |
| Частичная загрузка данных | Проверка целостности | Отклонить неполные данные, повторить запрос |
| Несоответствие схеме данных | Логирование ошибки | Отклонить данные, использовать кэшированную версию справочника |

### Интеграция №2 — Проверка номера телефона

| Ситуация | Действие | Поведение системы |
|----------|----------|-------------------|
| Сервис недоступен | 3 попытки с интервалом 1 секунда | Отобразить ошибку: "Сервис проверки номера недоступен" |
| Таймаут ответа | Прервать запрос через 3 секунды | Повторить запрос, при повторной неудаче — ошибка |
| Невалидный ответ | Проверка наличия обязательных полей | Логирование ошибки, повторный запрос |

### Интеграция №3 — Создание клиента

| Ситуация | Действие | Поведение системы |
|----------|----------|-------------------|
| Ошибка сохранения в БД | Откат транзакции | Не создавать клиента, вернуть ошибку 500 |
| Конфликт уникальности номера | Проверка перед вставкой | Вернуть ошибку 409, предложить другой номер |
| Частичное сохранение данных | Использование транзакций | Полный откат при любой ошибке |

### Интеграция №4 — Отправка SMS

| Ситуация | Действие | Поведение системы |
|----------|----------|-------------------|
| Основной SMS-провайдер недоступен | Переключение на резервного | Логирование переключения, попытка отправки через резервного |
| Все провайдеры недоступны | 3 попытки с интервалом 30 секунд | Отметить уведомление как failed, уведомить менеджера |
| Ошибка валидации номера | Проверка формата | Не отправлять SMS, вернуть ошибку UI для ручного ввода |
| Недостаточно средств | Логирование | Отметить уведомление как failed, уведомить администратора |

| Справочник | Система-источник | Система-получатель | Требование |

| `LinkChannelTypes` | UI (выбор менеджера) | API Backend | Идентификатор `channelTypeId` должен существовать в БД |
